# Skill-Pack Authority Specification

Status: approved bootstrap, 2026-08-29.

## repository-scope

This repository contains reusable AI-agent skills for NautilusTrader development only. It may change skills, references, templates, tests, and validation tooling inside this repository. It must not implement, prepare, commit, or publish changes to upstream NautilusTrader or unrelated downstream applications.

## upstream-authority

Upstream NautilusTrader source and official versioned documentation are read-only subject-matter ground truth. The mission resolves immutable upstream identities and validates currency before changing behavior-shaping guidance. Training-data memory, historical repository prose, and unpinned third-party examples are not compliance evidence.

## local-authority

Current skill content, repository instructions, executable validators, and tests define the implemented local contract. Approved specifications document stable behavior without outranking those executable surfaces. Tracker files preserve finding state, invariants, repository structure, and component readiness under their existing charters.

## shipping-authority

Phase 3 verification approval authorizes only read-only inspection and non-destructive validation. Phase 6 requires separate explicit user approval for commits, merges, pushes, releases, publication, or any other external write.
